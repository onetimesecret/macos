DESIGN NOTES
  • No auto-sort. Cells hold their position. The sort button (or ⌘S) cycles time left → A–Z; dragging a cell puts you back in manual order.
  • Empty cells are valid. Prep blank cells ahead of time: ⌘⏎ with an empty field, or double-click empty space. Removal is explicit — the × on each cell. No more silent vanish-on-blur.
  • On deck. The input is a staging area: safe to paste and hold. While it has content, an “On deck — not a cell yet” status shows (and is announced to screen readers). Clicking anywhere in the footer focuses it.
  • The clock restarts when a cell is edited or copied, at its current rung.
  • Expired cells collect in a counter at the bottom right; clicking flips to an expired list with per-cell Restore and Clear all. ⚠ The brief lists archives as an anti-goal — this needs a team decision before it ships.
  • Sync status. The header cloud is Local by default (cells stay on-device). Signed in, it shows a check and cells sync encrypted. Clicking opens the Local/Remote menu with a log-in action (demo: the button just toggles).
  • Pin. The keep-on-top toggle is now a real pin icon; filled = floating above other windows.
  • Masking removed for now. To add back later: automatic masking for content that looks like a secret, with a visible, predictable trigger.
  • Stacking. A cell is never shorter than one line. The window grows to 640px, then the list scrolls (normal two-finger scrolling).
