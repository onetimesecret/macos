v7 · reconciling v6 with the spec — six directions

Back inside the fixed constraints of docs/design-brief.md: secret-shaped content is masked again and there is no reveal (the bytes never reach the UI); the Recently-deleted bin is gone (expiry is silent — no retention); hover reveals actions, never content, so the countdown watermark retired with it. Kept from v6: time as geometry, the resizable panel (left/bottom edges — it docks top-right), and the click-to-cycle TTL label. Per your note the ring is retired everywhere — each direction below is a different answer to where its job goes. All six forms are static-first, so Reduce Motion needs no alternate design.
