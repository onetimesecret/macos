# State of the Onion

A State of the Onion is a dated snapshot of where OnetimePad stands: what shipped, what is in flight, and what is coming. The name is Larry Wall's, taken from the keynotes he gave on the state of Perl, and it suits a program named for an onion.

## Convention

- One file per entry, named `YYYY-MM-DD-state-of-the-onion.md`.
- An entry is a frozen record of its date. A later entry corrects an earlier one rather than editing it in place.
- The status of record is still GitHub issues and milestones (see `../ROADMAP.md`). A SOTO is the narrative around that status, not a replacement for it.
